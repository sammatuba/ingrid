# The integration contract: every desk question answered six ways

This page gives the same table as [the JSON contract](integration-contract.json). The table reads left to right for each desk question.
Each cell gives the finding, the surface that shows it, its status word and the record behind the word.
A surface is a site route, a repository path, or missing.
A missing surface names the reason.
The status word comes from the ladder above and never rises above its record.
The contract copies no figure from the owner's map.
Every word here rests on a repository record named in the cell.

The ladder names these five steps: selected design, code implemented, tests executed, recorded run, deployed.
The word missing marks an answer with no record.
`deployed` rests on a release record that names the revision. That record is `docs/work/PROGRESS.md`.
Batch release 7 names revision `grid-nowcast-00019-rpg` (release record, 2026-10-17).
A deployed answer names the word its page carries at that release commit.
